# Godrej Neopolis Hyderabad — Premium SEO Landing Page

Production-ready luxury real estate lead-generation website for **Godrej Neopolis**, Neopolis, West Hyderabad.

## Tech Stack

- HTML5 (semantic, SEO-first, crawlable)
- Tailwind CSS 3 / Custom Compiled CSS
- Vanilla JavaScript (Formspree CRM lead infrastructure, floating popups, analytics hooks)

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000` (or local dev server).
